# Student Grade Tracker

## CodeAlpha Java Programming Internship

### Task 1: Student Grade Tracker

This project is a simple Java-based Student Grade Tracker developed as part of the CodeAlpha Java Programming Internship.

The program allows users to enter student names and their marks and generates a summary report.

## Features

- Add multiple students
- Enter student marks
- Store student information using ArrayList
- Calculate average marks
- Find highest marks
- Find lowest marks
- Display a summary report

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Loops and Conditional Statements

## How the Program Works

1. The user enters the number of students.
2. The program asks for each student's name.
3. The user enters the marks of each student.
4. Student details are stored using an ArrayList.
5. The program calculates:
   - Average marks
   - Highest marks
   - Lowest marks
6. A complete student report is displayed.
